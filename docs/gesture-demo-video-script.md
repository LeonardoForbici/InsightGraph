# Gesture Demo Video Script (2 Minutes)

## Goal

Show scanner modes (local and GitHub) plus gesture control workflow with clear value in under 2 minutes.

## Timeline

### 0:00 - 0:20 Intro

- Open InsightGraph dashboard
- Show "Controle por Gestos (Beta)" panel
- Explain that scan and gesture control work together

### 0:20 - 0:55 Scanner mode: Local

- Select `Local`
- Start a scan for a local workspace
- Show progress metrics and completion status

### 0:55 - 1:25 Scanner mode: GitHub

- Switch to `GitHub`
- Fill `owner/repo`, branch, shallow clone
- Start scan and show progress/cancel behavior

### 1:25 - 1:50 Gesture control

- Enable gesture control
- Demonstrate:
  - pinch (select/drag)
  - v_sign / closing_v (zoom in/out)
  - fist (deselect)
  - palm_forward (pause/resume)

### 1:50 - 2:00 Close and roadmap

- Mention current beta status
- Mention roadmap:
  - stronger multi-hand semantics
  - configurable custom gestures
  - deeper adaptive performance profiles

## Performance comparison notes

- Local mode:
  - no network clone overhead
  - best for active local repositories
- GitHub mode:
  - ideal when repository is remote-only
  - supports shallow clone for faster first scan
